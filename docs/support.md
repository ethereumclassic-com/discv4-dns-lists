# Support this work

**These discovery trees are maintained as a public good, and they are
unfunded.** This page is the one place this repository publishes its funding
routes. If you find them anywhere else, check them against this page first.

## What the funding pays for

Keeping Ethereum Classic's peer discovery working every night: running the
pipeline that crawls the network and publishes the trees, keeping the three
domains registered and their DNS served, answering a refused run on the
[status issue](https://github.com/ethereumclassic/discv4-dns-lists/issues?q=label%3Apipeline-status),
and updating the fork pins when the network passes a fork.

## Who depends on it

Every node that starts from these trees: mining pools, centralized exchanges and
custodians, block explorers, RPC providers, and anyone running an Ethereum
Classic node. **Ethereum Classic has no protocol treasury**, so no part of the
network's fee or issuance revenue funds this work. If the trees are maintained,
someone with a stake in the chain pays for it.

## How to fund it

**An invoiced agreement, for organizations.** If your business depends on these
trees, a maintenance sponsorship can be invoiced against a purchase order like
any other vendor relationship, which is usually what a finance department needs.
Write to <donations@ethereumclassic.net> with what you run and the period you
want to cover.

**A direct transfer.** For anyone who prefers to send funds directly, an address
is provided on request. Write to <donations@ethereumclassic.net>. If a large
transfer is planned, send a small one first and confirm receipt at the same
address.

**This project does not publish a donation address.** An address shown in a
screenshot, a fork, a mirror or a message did not come from this project unless
it arrived in a reply from <donations@ethereumclassic.net>.

Funding mail goes to `ethereumclassic.net`, the domain for the public goods
maintained in the [`ethereumclassic`](https://github.com/ethereumclassic)
organization, including these trees and the
[Core-Geth](https://github.com/ethereumclassic/core-geth) client.

## What funding does not buy

**No place in the trees.** A node is listed on
[the same criteria](node-selection.md#what-gets-a-node-listed) as every other,
whoever runs it and whoever funds this work, and every list published is committed
here, where anyone can check it.

Requests and reports are welcome from anyone, funded or not, in
[this repository's issues](https://github.com/ethereumclassic/discv4-dns-lists/issues).
